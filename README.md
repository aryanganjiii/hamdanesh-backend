# بک‌اند هم‌دانش

سرویس بک‌اند هم‌دانش با FastAPI پیاده‌سازی شده است. این برنامه اسناد را پردازش و در SQLite نگهداری می‌کند، قطعه‌های مرتبط را با بازیابی ترکیبی پیدا می‌کند و پاسخ‌های دستیار را بر پایهٔ شواهد و همراه با ارجاع به منبع برمی‌گرداند.

## ساختار

- `app/domain`: موجودیت‌ها، قراردادها، نرمال‌سازی فارسی و قطعه‌بندی متن
- `app/services`: ورود سند، بازیابی ترکیبی و ساخت پاسخ چت
- `app/infrastructure`: parser، repository و کلاینت AvalAI
- `app/api`: مسیرهای HTTP و schemaهای درخواست و پاسخ
- `sample_documents`: اسناد ساختگی برای اجرای نمونه
- `data`: پایگاه SQLite که هنگام اجرا ساخته می‌شود

## پیش‌نیازها

- Python 3.10 یا جدیدتر
- کلید API در AvalAI برای فعال‌بودن پاسخ‌گویی هوشمند

## اجرا در Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
python main.py
```

در فایل `.env` مقدار `AVALAI_API_KEY` را با کلید خودتان جایگزین کنید. فایل `.env` و پایگاه دادهٔ محلی در Git نادیده گرفته می‌شوند؛ کلید را در کد یا فایل‌های commitشده قرار ندهید.

API روی `http://127.0.0.1:8000` اجرا می‌شود و مستندات تعاملی آن در `http://127.0.0.1:8000/docs` قرار دارد.

## تنظیمات مهم

تنظیمات قابل تغییر در `.env.example` آمده‌اند. مسیر پیش‌فرض پایگاه داده `data/knowledge.sqlite3` است. اندازهٔ فایل ورودی، اندازه و هم‌پوشانی قطعه‌ها، مدل‌های چت و embedding و سقف طول پاسخ نیز از متغیرهای محیطی خوانده می‌شوند.

## ملاحظات نسخهٔ دانشگاهی

اسناد پوشهٔ `sample_documents` برای نمایش ساخته شده‌اند. این نسخه احراز هویت و مجوز چندکاربره ندارد و برای نگهداری اسناد محرمانه یا استقرار عملیاتی آماده نشده است. متن قطعه‌ها و پرسش‌ها برای embedding یا تولید پاسخ به provider پیکربندی‌شده ارسال می‌شوند.
